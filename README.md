## 🧾 Executive Overview

Principal C# engineer at **Asteria Interactive™** with end-to-end ownership of native Windows desktop, cross-platform desktop, and shipped Godot 4 games — all in **C# 13 / .NET 9**.

I design and ship:

- **Native Windows** product surfaces in **WinUI 3 + Windows App SDK**, packaged as **MSIX**, signed, and identity-aware.
- **Cross-platform desktop** in **Avalonia 11** so the same C# core runs on Windows, Linux, and macOS without WinRT.
- **Games** in **Godot 4 .NET**, with C# gameplay, tools, and exporters — not GDScript-first, not Unity.

Build graphs are **MSBuild + `dotnet` CLI**, pinned by `global.json` and central NuGet. IDEs are **Visual Studio 2022**, **JetBrains Rider**, **VS Code + C# Dev Kit**, and the **Godot 4 .NET editor**.

> **Note:** The prior C / C++ / Rust / Assembly systems stack, and the older Node.js / TypeScript web stack, have been **retired**. Active work is C# — desktop, tools, and games.

## 🛠️ Core Technical Domains

> ### 🪟 Native Windows Desktop (WinUI 3)
> Architectural design and production implementation of Windows 11 desktop software in **C# / WinUI 3 / Windows App SDK**. AppWindow, Mica, MSIX identity, push, windowing, and Fluent composition. Visual Studio 2022 is the primary debugger.

> ### 🌐 Cross-Platform Desktop (Avalonia)
> Multi-OS desktop in **Avalonia 11** — Skia rendering, AXAML, compiled bindings — targeting Windows, Linux, and macOS from one `net9.0` csproj. Rider previewer + `dotnet publish` (folder, zip, NativeAOT where it fits).

> ### 🎮 Godot 4 Game Development (C#)
> First-party games under `src/Godot-Projects`. Scene composition in the Godot editor; **all first-party logic in C#** (`Godot.NET.Sdk`). Signals, autoloads, import pipelines, and headless CI exports for Windows / Linux / macOS.

> ### 🧩 Platform Engineering & Tooling
> `global.json`, `Directory.Build.props`, central package management, GitHub Actions matrices, Authenticode, Godot export templates, and Git LFS for art. One C# language service across VS, Rider, and VS Code.

## 🧠 Engineering Principles (personal)

1. **One language beats a clever FFI graph.** C# 13 covers desktop, tools, and games. I retired the C++ / Rust / Assembly stack on purpose.
2. **Windows gets WinUI. POSIX gets Avalonia.** Do not pretend one UI tree serves both well.
3. **Godot editor for scenes, C# for systems.** GDScript is for other people's addons.
4. **Nullable, analyzers, deterministic SDK.** If it only builds on a preview SDK, it does not ship.
5. **Ship signed.** MSIX + Authenticode on Windows; notarization on macOS; matching Godot export templates in CI.
