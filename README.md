## 🧾 Executive Overview

Principal engineer at **Asteria Interactive™** with end-to-end ownership of native systems software and desktop products, written in **C, C++, Rust, and Assembly** with **Qt 6** on top.

I design and ship:

- 🧊 **Stable C-ABI cores**: small, auditable C17 libraries whose headers are the contract between every other layer.
- ⚙️ **C++20/23 engines and services**: RAII-first platform layers, containers, and application logic that never touches a `QApplication`.
- 🦀 **Rust subsystems**: memory-hard modules (parsers, protocols, concurrency) bridged to C++ and Qt at the app edge.
- 🧮 **Hand-tuned Assembly**: profiled hot paths in NASM / MASM with a C reference, a test, and a benchmark behind every routine.
- 🪟 **Qt 6 desktop apps**: Widgets and QML front-ends, built with CMake, packaged and signed for Windows, Linux, and macOS.

Build graphs are **CMake + Ninja**, with **vcpkg** (pinned baseline) for C/C++ and **Cargo** (locked) for Rust. On Windows the compiler is the **MSVC Build Tools** (no full IDE needed). Day-to-day IDEs are **JetBrains CLion** and **RustRover**.

> **Note:** The earlier C# / .NET / WinUI / Avalonia / Godot track has been **retired**. Active work is native: systems libraries and Qt desktop software.

## 🧩 Core Technical Domains

> ### 🧊 C and C++ Systems
> Architecture and production implementation of native libraries and engines in **C17 and C++20/23**. Stable C ABIs, RAII, no exceptions across module boundaries, thin platform layers, and zero-warning builds on MSVC, Clang, and GCC.

> ### 🦀 Rust
> Memory-safe subsystems in **Rust 2024**: `#![forbid(unsafe_code)]` by default, audited `unsafe` behind documented `// SAFETY:` invariants, Miri in CI, and FFI through `cxx`, `cbindgen`, and Corrosion.

> ### 🧮 Assembly
> Performance-critical kernels in **NASM, MASM (`ml64`), and GAS**. Documented calling conventions, clobbers, and CPU-feature dispatch, always paired with a portable C fallback.

> ### 🪟 Qt 6 Desktop
> Cross-platform desktop products in **Qt 6 / C++**: Widgets for dense tooling UI, QML for fluid interfaces, Designer `.ui` workflows, `tr()` + Linguist localization, and `windeployqt` / `macdeployqt` / `linuxdeploy` packaging.

> ### 🧱 Platform Engineering & Tooling
> `CMakePresets.json`, vcpkg manifests, `rust-toolchain.toml`, GitHub Actions matrices, sanitizer jobs (ASan / UBSan / TSan), Authenticode signing, macOS notarization, SBOMs, and Git LFS for art and installers.

## 🧠 Engineering Principles (personal)

1. **Native first, right tool per layer.** C for ABIs, C++ for engines and UI, Rust for memory-hard code, Assembly for proven hot paths.
2. **Qt is the shell, not the foundation.** If the logic needs a window to be tested, it is in the wrong place.
3. **Measure, then optimize.** No assembly, no `unsafe`, no cleverness without a profile and a test.
4. **Zero warnings, sanitizers on.** `/W4 /WX`, `-Wall -Wextra -Werror`, ASan / UBSan / TSan, Miri. If it only builds with warnings off, it does not ship.
5. **Same commit + same pins = same artifact.** Pinned compilers, locked dependencies, out-of-source builds.
6. **Ship signed.** Authenticode on Windows, notarization on macOS, SBOM with every release.
