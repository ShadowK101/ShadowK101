## 🧾 Executive Overview

Principal Full-Stack and Platform Engineer with end-to-end architectural experience spanning native Windows desktop applications, JVM backend services & Android clients, and modern web platforms.

Specializing in **C#** and **.NET 8** with **WinUI 3** on the **Windows App SDK** for fully native, Fluent-Design desktop applications; **Kotlin** (Java-interoperable) on the **JVM** via **Gradle** for backend services, shared libraries, and Android clients; and **Node.js** with **TypeScript** (and plain JavaScript where warranted) for web applications and HTTP APIs. All workspaces are heavily optimized and managed through elite **Visual Studio 2022**, **JetBrains Rider / IntelliJ IDEA**, and **VS Code** configurations.

---

## 🛠️ Core Technical Domains

> ### 🪟 WinUI 3 & Native Windows Applications
> Architectural design and production implementation of native, Fluent-Design desktop applications using **WinUI 3** and the **Windows App SDK** — MSIX-packaged, cryptographically signed, and distributed through both sideload and Microsoft Store channels, managed inside **Visual Studio 2022**.

> ### ☕ Kotlin, Java & JVM Services
> Engineering backend services, shared libraries, and Android clients on the **JVM** — **Kotlin**-first with full **Java** interoperability, **Gradle**-driven builds, **Spring Boot**/**Ktor** service architecture, coroutine-based concurrency, and **Jetpack Compose** Android UIs, iterated inside **IntelliJ IDEA** and **JetBrains Rider**.

> ### 🌐 Node.js, TypeScript & Web Platforms
> Building web applications and HTTP APIs on **Node.js** with **TypeScript** — type-safe service boundaries, **React**/**Next.js** frontends, REST/GraphQL API design, and modern bundler tooling (Vite/Next.js), developed and debugged inside **VS Code**.

> ### 🧩 Shared Architecture & Build Systems
> `Directory.Build.props`, Gradle version-catalog (`libs.versions.toml`), and `pnpm-workspace.yaml` convention discipline for reproducible builds across every project, strict lint/format gates (`dotnet format`, `ktlint`/`spotless`, `eslint`/`prettier`), and CI/CD matrices that ship MSIX packages, JVM artifacts, and web bundles simultaneously.

## 🎯 Core Active Directives

* **Native Desktop Application Suite:** Architecting Fluent-Design Windows applications with WinUI 3 on the Windows App SDK, packaged and signed via MSIX (`src/Desktop`).
* **JVM Backend & Android Systems:** Building Kotlin/Java services, shared libraries, and Jetpack Compose Android clients on Gradle, deployed via Spring Boot/Ktor (`src/JVM`).
* **Web Platform Engineering:** Shipping TypeScript-first Node.js APIs and React/Next.js frontends with strict type-safety and CI-enforced lint/format gates (`src/Web`).
* **Monorepo System Tooling:** Streamlining MSBuild convention logic, Gradle version catalogs, pnpm workspace boundaries, and CI/CD multi-target deployment across Visual Studio, Rider/IntelliJ, and VS Code (`src/Tools`).
