## 🧾 Executive Overview

Principal Systems and Platform Engineer with end-to-end architectural experience in cross-platform native software — from hand-tuned Assembly and C at the metal, through C++ application and library layers, to Rust for memory-safe systems components.

Specializing in **C** and **C++** across **MSVC**, **Clang/LLVM**, and **GCC** toolchains for portable, high-performance native binaries; **Rust** for concurrency-safe systems services and hardened components; and **x86-64 / ARM Assembly** for low-level optimization, calling-convention work, and performance-critical hot paths. Builds target **Windows, Linux, and macOS** from unified **CMake**, **Ninja**, and **Cargo** build graphs, with all workspaces managed through elite **Visual Studio 2022**, **CLion**, and **VS Code** configurations.

> **Note:** The prior C#/.NET/WinUI 3 desktop stack and the Node.js/TypeScript web stack have been deprecated in favor of this native, cross-platform direction. `src/Desktop` and `src/Web` are retained as legacy/archival only.

---

## 🛠️ Core Technical Domains

> ### ⚙️ Native Systems Engineering (C / C++)
> Architectural design and production implementation of cross-platform native software in **C** and **C++**, compiled across **MSVC**, **Clang/LLVM**, and **GCC** toolchains — portable build graphs via **CMake**/**Ninja**, targeting Windows, Linux, and macOS from a single codebase where possible.

> ### 🦀 Rust Systems Components
> Memory-safe systems services, native libraries, and FFI-exposed components built in **Rust**, managed via **Cargo** workspaces, with `unsafe`-audited interop boundaries into C/C++ codebases where native ABI compatibility is required.

> ### 🔩 x86-64 / ARM Assembly
> Hand-written and hand-tuned **Assembly** (x86-64 and ARM) for hot-path optimization, SIMD/vectorized routines, calling-convention and ABI work, and low-level primitives that sit beneath the C/C++/Rust layers.

> ### 🧩 Shared Architecture & Build Systems
> `CMakePresets.json`, Cargo workspace manifests, and toolchain files for reproducible builds across every project; strict lint/format gates (`clang-format`, `clang-tidy`, `rustfmt`, `clippy`); and CI/CD matrices that produce Windows (MSVC), Linux (GCC/Clang), and macOS (Clang) binaries simultaneously.

## 🎯 Core Active Directives

* **Cross-Platform Native Core:** Architecting portable C/C++ systems software compiled across MSVC, Clang/LLVM, and GCC, targeting Windows, Linux, and macOS from a unified CMake/Ninja build graph (`src/Systems`).
* **Rust Systems Components:** Building memory-safe, Cargo-managed Rust services and libraries with audited FFI boundaries into the native C/C++ layer (`src/Systems`).
* **Low-Level Optimization:** Hand-tuning x86-64/ARM Assembly for hot paths, SIMD routines, and ABI-critical primitives beneath the higher-level layers.
* **Monorepo System Tooling:** Streamlining CMake presets, Cargo workspace manifests, cross-compiler toolchain files, and CI/CD multi-target deployment across Visual Studio, CLion, and VS Code (`src/Tools`).
